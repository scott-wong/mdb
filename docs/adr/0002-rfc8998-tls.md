# ADR 0002: RFC 8998 TLS 1.3 instead of TLCP

## Status

Accepted.

## Decision

The national-cryptography profile uses RFC 8998:

- TLS 1.3 only;
- SM2 certificate and SM2 signature;
- SM2 key exchange (`Groups=SM2`);
- SM3 transcript hashing;
- SM4-GCM record protection.

Tongsuo is built without `enable-ntls`. TLCP/NTLS is explicitly out of scope.

## Consequences

Standard TLS clients cannot negotiate with an SM2-only listener. Standard and GM
profiles therefore use separate processes/listeners, or an external TLS
terminator when both must be exposed.
